# A/B-тест нового алгоритма рекомендаций

Учебный проект Яндекс Практикума, спринт «Анализ результатов A/B-тестирования с помощью Python».

## Задача
Приложение с «бесконечной» лентой проверяет новый алгоритм рекомендаций. Нужно рассчитать параметры A/B-теста, проверить корректность его проведения и оценить влияние на долю успешных первых сессий (4 и более просмотренных страниц).

## Данные
Сессии пользователей приложения за исторический период (15.08–23.09.2025) и за период теста (14.10–02.11.2025): идентификаторы пользователя и сессии, даты, число просмотренных страниц, регион, устройство, тестовая группа. Датасет предоставлен Яндекс Практикумом и в репозиторий не включён.

## Что сделано
- EDA исторических данных: динамика аудитории, регистраций и глубины просмотра; базовая доля успешных первых сессий — около 31%;
- расчёт размера выборки (α = 0,05, мощность 0,8, относительный MDE 3%): 41 040 пользователей на группу, расчётная длительность теста — около 9 дней;
- проверка корректности теста: расхождения размеров групп (SRM) нет, пересечений пользователей нет, распределения по устройствам и регионам совпадают;
- z-тест для двух долей: группа A — 31,57%, группа B — 31,47%, p-value = 0,578;
- анализ ограничений: фактическая выборка — около 37% от расчётной, достигнутая мощность — около 40%.

## Вывод
Статистически значимого роста ключевой метрики нет, внедрять алгоритм по результатам этого теста не стоит. Рекомендован повторный тест с корректно рассчитанной выборкой, учётом притока новых пользователей и отслеживанием прокси- и барьерных метрик.
